# 🤰 Maternal Health Data Analysis  

## 📌 Project Overview  
This project focused on analyzing a **comprehensive maternal health dataset** containing 115 variables, including **ultrasound findings, nutrition, clinical screenings, delivery outcomes, and newborn health metrics**.  

The goal was to **evaluate maternal factors influencing pregnancy and newborn outcomes**, build a structured star schema for analysis, and provide actionable insights through **interactive Power BI dashboards**.  

---

## 🎯 Objectives  
- Prepare and transform a large maternal health dataset with **115 clinical and lifestyle variables**.  
- Design a **star schema** with fact tables (Hospitalization & Labor, Newborn) and dimension tables (Diet, Medical History, Vitals, Labs).  
- Clean and standardize categorical and numeric data using SQL-based ETL processes.  
- Develop **Power BI dashboards with DAX measures** to analyze maternal anthropometry, nutrition, screenings, and neonatal outcomes.  
- Deliver insights into **maternal factors affecting labor and newborn health**.  

---

## 🛠 Tools & Skills  
- **SQL (ETL)** – Data extraction, cleaning, transformation, and schema design.  
- **Power BI** – Data modeling, DAX measures, KPIs, and dashboard development.  
- **Data Modeling** – Star schema design with fact and dimension tables.  
- **ETL Documentation & Version Control** – Ensured reproducibility and consistency.  

---

## 📊 Key Features  
- Designed and implemented a **star schema** for efficient querying and reporting.  
- Performed **extensive ETL in SQL**, including categorical/numeric conversions and handling missing values.  
- Built **interactive Power BI dashboards** analyzing maternal anthropometry, ultrasound data, and newborn outcomes.  
- Applied **advanced DAX** for trends, comparisons, and KPI metrics to support clinical decision-making.  
- Coordinated ETL documentation and SQL version control to maintain project integrity in a **team setting**.
