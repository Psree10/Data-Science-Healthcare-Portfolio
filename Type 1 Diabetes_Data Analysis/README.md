# 💉 Type 1 Diabetes Management Analysis  

## 📌 Overview  
This project focused on analyzing **Type 1 diabetes patient management data** with an emphasis on **insulin therapy, carbohydrate intake, and sleep patterns**. Using Python, I performed data wrangling, statistical analysis, and visualization to uncover insights into how insulin bolus/basal doses, diet, and lifestyle factors influence glucose management.  

---

## 🎯 Objectives  
- Analyze **insulin bolus and basal dose patterns** in relation to carbohydrate intake.  
- Study the impact of **sleep duration and quality** on glucose variability.  
- Identify correlations between **diet, insulin management, and lifestyle** for diabetes care.  
- Build **visualizations** to track patterns and present insights effectively.  

---

## 🛠 Tools & Skills  
- **Python** – Data wrangling, statistical analysis, and visualization.  
- **pandas** – Data cleaning and tabular analysis.  
- **NumPy** – Numerical computations.  
- **matplotlib & seaborn** – Exploratory and comparative visualizations.  
- **plotly** – Interactive charts for deeper data exploration.
- **Machine Learning:** - For predictive analysis

---

## 📊 Key Features  
- Processed and structured patient-level datasets with **insulin dosing, carbohydrate intake, and sleep logs**.  
- Created **time-series visualizations** showing insulin vs carb intake across different time periods.  
- Analyzed the effect of **sleep habits on glucose variability** using correlation plots and trend analysis.  
- Built interactive visualizations for **carb-insulin balance, dosage trends, and lifestyle patterns**.  
- Delivered insights to better understand **diabetes self-management behaviors**.
